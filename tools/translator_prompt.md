# Инструкция переводчику Roadwarden (EN → RU)

Ты переводишь текстовую RPG **Roadwarden** (движок Ren'Py, мрачное низкое фэнтези, повествование во втором лице) с английского на русский для личного использования. Проект: /Volumes/fury/projects/roadwarden.

## Порции
Каждая порция — это `work/<name>.json` = `{"file": "<исходный .rpy>", "items": [{"id", "en"}]}`, строки идут в порядке сценария.
Для каждой порции запиши рядом `work/<name>.ru.json` = `{"<id>": "<русский текст>"}`, **все** id из порции.
JSON в UTF-8 и валидный; перенос строки записывай как `\n` там же, где он есть в английском.
Удобнее всего писать файл инструментом Write; если делаешь это из Python, используй `ensure_ascii=False`.

## Правила
1. **Сначала полностью прочитай /Volumes/fury/projects/roadwarden/glossary.md и строго ему следуй**: имена, места, существа, предметы, задания, термины, типографика («», —), тон.
   - Повествование обращается к герою на «ты», в настоящем времени.
   - Герой мужского рода.
   - Варианты ответа и записи в истории — от первого лица, в мужском роде («Я помог», «Я ухожу»).
2. Сохраняй **дословно**:
   - теги `{...}`;
   - подстановки `[...]`;
   - `%s` / `%d`;
   - `[[`;
   - суффикс ` (disabled)`;
   - число абзацев `\n\n`.

   Пробелы по краям строки не нужны: игра восстанавливает их сама.
3. Многие строки хранятся в переменных и склеиваются при выводе:
   - `'[custom1]'` или `'[x_fluff][custom1]'` — фрагменты, собираемые в одну реплику;
   - списки `renpy.random.choice([...])` — взаимозаменяемые варианты фразы;
   - записи истории `- “…”` — они повторяют выбранный вариант ответа, переводи их так же, как сам вариант;
   - описания в дневнике (`description_*`, `quest_*_description*`).

   Если неясно, как куски стыкуются, найди id в /Volumes/fury/projects/roadwarden/data/strings.json (там исходный файл и строка) и прочитай исходник в `~/Library/Application Support/Steam/steamapps/common/Roadwarden/Roadwarden.app/Contents/Resources/autorun/game/`. Игру **только читай**, ничего в ней не меняй.
4. Литературное качество важно: оригинал атмосферный и сжатый. Переводи смысл и голос, а не слова. Избегай калек и канцелярита. Реплики персонажей должны звучать живо, у каждого свой характер.
5. Числа в подстановках (`[custom1]` дней, `[x]` монет) не согласуются с существительным, поэтому строй фразу так, чтобы падеж не зависел от числа: «Осталось дней: [custom1]», «Цена: [x]».
6. Говор: жители Ручьёв говорят простецки, Племя Зелёной Горы — архаично. Передавай это умеренно (см. глоссарий).
7. Строки, которые выглядят как код (`"color, i, image"`, пути к файлам `audio/…`, условия), оставь без перевода. Валидатор пометит их — это нормально, просто упомяни их в отчёте.

## Проверка
После каждой порции запусти:
`python3 -I /Volumes/fury/projects/roadwarden/tools/validate.py /Volumes/fury/projects/roadwarden/work/<name>.ru.json`

Исправляй все MISSING / PROBLEM / INVALID JSON и повторяй проверку, пока не будет 0 missing и 0 problems (кроме строк-кода из п. 7).

Не трогай другие файлы: glossary.md, tools/, translations/ и чужие порции.

## Отчёт (коротко, по-русски)
- По каждой порции: сколько строк и результат проверки.
- Список **новых** имён, мест, предметов и терминов, которых нет в глоссарии (EN → RU, по одному в строке, в базовой форме).
- Только реальные сомнения — что стоит решить на уровне всей игры.
