Неофициальный русификатор Roadwarden
====================================

Внимание: перевод машинный, его целиком сделала нейросеть Claude Opus (Anthropic).
Это черновик: его ещё не вычитывали и не проходили целиком,
возможны ошибки и неточности (например, в роде персонажей).

Нужна купленная игра Roadwarden (Steam или GOG). Архив не содержит
файлов игры, только перевод.

Установка
---------
Скопируйте папку zz_russian внутрь папки game игры.

  Windows (Steam):
    Steam → Roadwarden → правой кнопкой → Управление → Просмотреть локальные файлы,
    затем откройте папку game (она лежит рядом с Roadwarden.exe).

  Linux (Steam):
    ~/.local/share/Steam/steamapps/common/Roadwarden/game/

  macOS (Steam):
    Steam → Roadwarden → правой кнопкой → Управление → Просмотреть локальные файлы,
    затем на Roadwarden.app правой кнопкой → Показать содержимое пакета →
    Contents/Resources/autorun/game/

В итоге должно получиться: game/zz_russian/ru_hook.rpy и game/zz_russian/ru_strings.json.

В игре
------
F9 переключает русский и английский.
Сохранения совместимы с оригиналом: перевод меняет только то, что выводится на экран.

Удаление
--------
Удалите папку game/zz_russian.

Известные ограничения
---------------------
- Там, где игра просит ввести слово с клавиатуры (поиск слухов, загадки),
  вводить нужно по-английски.
- Пиксельный шрифт оригинала не поддерживает кириллицу, поэтому вместо него
  используется шрифт Philosopher, который уже есть в игре.
- Проверено на версии 1.2.0 (macOS, Steam).
