# Русификатор Roadwarden (неофициальный, машинный перевод)

Русский перевод текстовой RPG [Roadwarden](https://store.steampowered.com/app/1155970/Roadwarden/).

> **Перевод целиком сделан нейросетью Claude Opus (Anthropic). Человек его не вычитывал.**
> Играть можно, текст читается нормально, но шероховатости есть. Список ниже.
> Если нашли ошибку, создайте issue и приложите цитату или скриншот.

**Нужна купленная игра** (Steam или GOG). В репозитории и архивах нет файлов игры и её
английского текста, только русский перевод и скрипт, который подставляет его при выводе на экран.
Это любительский проект, он никак не связан с разработчиками игры. Все права на Roadwarden
принадлежат им.

## Как поставить
1. Скачайте архив `roadwarden-ru-<дата>.zip` из раздела [Releases](../../releases).
2. Скопируйте папку `zz_russian` из архива в папку `game` игры:
   - **Windows / Linux:** Steam → Roadwarden → правой кнопкой → Управление → Просмотреть локальные
     файлы, затем откройте папку `game` (она лежит рядом с исполняемым файлом игры).
   - **macOS:** сначала так же откройте локальные файлы игры, затем на `Roadwarden.app` нажмите
     правой кнопкой → «Показать содержимое пакета» → `Contents/Resources/autorun/game`.

   Должно получиться: `game/zz_russian/ru_hook.rpy` и `game/zz_russian/ru_strings.json`.
3. Запустите игру как обычно, хоть через Steam. Текст будет на русском.

- **F9** в игре переключает русский и английский. Удобно, если фраза звучит странно.
- Сохранения совместимы с оригиналом в обе стороны.
- Чтобы удалить русификатор, удалите папку `game/zz_russian`.
- Если обновление игры удалит папку, просто скопируйте её снова.

## Как делался перевод
- Весь текст игры (около 717 тысяч английских слов) перевела модель **Claude Opus** в Claude Code.
  Текст был нарезан на порции примерно по 2500 слов, и их параллельно переводили отдельные
  экземпляры модели.
- Все переводчики работали по общему [глоссарию](glossary.md): имена, места, термины, говоры
  поселений, типографика. По ходу работы его пополняли и выравнивали расхождения между порциями.
- Каждую порцию автоматически проверяли скрипты: что не сломаны теги, подстановки и абзацы.
  Смысл и стиль так не проверишь.
- Человек задавал направление (герой мужского рода, повествование на «ты»), прошёл часть игры
  и сообщил о замеченных проблемах. **Построчной вычитки человеком не было.**

## Шероховатости
- **Род персонажей.** Иногда «он» и «она» перепутаны. Чаще всего там, где игра собирает фразу
  из кусков и подставляет имя позже: переводчик куска не всегда знал, о ком речь.
- **Разнобой в терминах.** Разные порции переводились параллельно, поэтому одно и то же слово
  местами переведено по-разному (например, «броня» и «доспех», «банда» и «шайка»).
- **Стиль.** Встречаются неуклюжие или слишком буквальные фразы. Говоры жителей
  (просторечие, архаика) переданы неровно.
- **Ввод с клавиатуры.** Там, где игра просит напечатать слово (поиск слухов, осмотр дольмена,
  алтарь, имена), вводить нужно **по-английски**: игра сравнивает ввод с английскими словами.
- **Шрифт.** В пиксельном шрифте Munro нет кириллицы, поэтому вместо него используется Philosopher
  (он уже есть в игре). Выглядит иначе, чем оригинал.
- **Платформы.** Проверено только на macOS (Steam, версия игры 1.2.0). Ren'Py одинаков на всех
  системах, так что должно работать и на Windows и Linux, но там не проверялось.

Известные проблемы, которые стоит поправить при вычитке, собраны в
[data/review_notes.md](data/review_notes.md).

## Как это устроено
Игра на Ren'Py 7.5.2. Сценарий не меняется: `hook/ru_hook.rpy` перехватывает вывод текста
(реплики, меню, экраны, подстановки `[var]`, историю) и подменяет строку русской, если она есть
в таблице. Таблица хранит не английский текст, а хэш от него (sha1). Игровые переменные остаются
английскими, поэтому логика игры и сохранения не затрагиваются.

## Для тех, кто хочет помочь или собрать сам
Нужны Python 3 и своя копия игры: английский текст берётся из неё и в репозиторий не попадает.

```bash
export ROADWARDEN_GAME="/путь/к/Roadwarden/game"   # на macOS по умолчанию берётся путь Steam
python3 -I tools/extract.py           # строки игры -> data/strings.json (только локально)
python3 -I tools/status.py            # прогресс по файлам
python3 -I tools/build.py --install   # собрать и поставить в игру
python3 -I tools/build.py --zip       # собрать архив для релиза
```

- `translations/<файл>.json`: перевод в виде `{id строки: {ru, status}}`. ID — это хэш английского
  текста, поэтому после обновления игры готовый перевод сохраняется.
  `status` бывает `draft` (машинный черновик) или `reviewed` (вычитано).
- `glossary.md`: имена, термины, тон и типографика. Его обязательно соблюдать при правках.
- `data/manual_ru.json`: ручные переводы одиночных слов, которые игра склеивает в фразы.
- `data/review_notes.md`: известные проблемы, которые нужно поправить при вычитке.
- Перевод новых кусков: `tools/chunk.py` режет непереведённые строки на порции в `work/`,
  `tools/validate.py` проверяет порцию (теги, подстановки, абзацы), `tools/merge.py` переносит
  её в `translations/`. Инструкция для переводчика лежит в `tools/translator_prompt.md`.

Чтобы найти непереведённые строки, запустите игру с `RU_DEBUG=/tmp/ru_missing.txt`: туда
запишется английский текст, для которого не нашлось перевода.
