# Русификатор Roadwarden (неофициальный, машинный перевод)

Русский перевод текстовой RPG [Roadwarden](https://store.steampowered.com/app/1155970/Roadwarden/).

> **Перевод сделан нейросетью Claude (Anthropic), это черновик.**
> Человек его ещё не вычитывал: возможны ошибки, неуклюжие фразы и разнобой в терминах.
> Целиком в игре перевод тоже ещё никто не проходил. Часть игры пока на английском. Если нашли ошибку, создайте issue и приложите цитату или скриншот.

**Нужна купленная игра** (Steam или GOG). В репозитории и архивах нет файлов игры и её
английского текста, только русский перевод и скрипт, который подставляет его при выводе на экран.
Это любительский проект, он никак не связан с разработчиками игры. Все права на Roadwarden
принадлежат им.

## Сколько переведено
Черновик готов примерно на 76% текста (по словам).
- Готово: интерфейс, дневник и энциклопедия, пролог, начало игры и окрестности, Туманное Озеро,
  Ручьи, Лощина Ревуна, Штормовые Скалы и побережье, Белые Топи, болота, пещеры друидов,
  Племя Зелёной Горы, Старый Пагос, короткая тропа, подготовка к Высокому Острову.
- Частично: Высокий Остров, монастырь, логово разбойников.
- Пока на английском: дом Евдокии, туннели, разрушенные деревня и приют, Созерцатель, дольмен,
  хижина охотника, большие случайные встречи, эпилоги.

## Установка
1. Скачайте архив `roadwarden-ru-<дата>.zip` из раздела [Releases](../../releases).
2. Скопируйте папку `zz_russian` из архива в папку `game` игры:
   - **Windows / Linux:** в папке игры (Steam → Управление → Просмотреть локальные файлы) откройте `game`.
   - **macOS:** на `Roadwarden.app` правой кнопкой → «Показать содержимое пакета» →
     `Contents/Resources/autorun/game`.
3. Запустите игру. **F9** переключает русский и английский.

Чтобы удалить русификатор, удалите папку `game/zz_russian`. Сохранения совместимы с оригиналом
в обе стороны. Подробности в [INSTALL.txt](INSTALL.txt).

## Известные ограничения
- Там, где игра просит ввести слово с клавиатуры (поиск слухов, загадки Созерцателя),
  ответ нужно вводить по-английски.
- Пиксельный шрифт Munro не содержит кириллицы, поэтому вместо него используется Philosopher
  (он уже есть в игре).
- Проверено на версии игры 1.2.0 (macOS, Steam). Ren'Py одинаков на всех системах, так что
  должно работать и на Windows и Linux, но там перевод пока не проверялся.

## Как это устроено
Игра на Ren'Py 7.5.2. Сценарий не меняется: `hook/ru_hook.rpy` перехватывает вывод текста
(реплики, меню, экраны, подстановки `[var]`, историю) и подменяет строку русской, если она есть
в таблице. Таблица хранит не английский текст, а хэш от него (sha1). Игровые переменные остаются
английскими, поэтому логика игры и сохранения не затрагиваются.

## Для тех, кто хочет помочь или собрать сам
Нужны Python 3 и своя копия игры: английский текст берётся из неё и в репозиторий не попадает.

```bash
export ROADWARDEN_GAME="/путь/к/Roadwarden/game"   # на macOS по умолчанию берётся путь Steam
python3 -I tools/extract.py           # строки игры -> data/strings.json (только локально)
python3 -I tools/status.py            # прогресс по файлам
python3 -I tools/build.py --install   # собрать и поставить в игру
python3 -I tools/build.py --zip       # собрать архив для релиза
```

- `translations/<файл>.json`: перевод в виде `{id строки: {ru, status}}`. ID — это хэш английского
  текста, поэтому после обновления игры готовый перевод сохраняется.
  `status` бывает `draft` (машинный черновик) или `reviewed` (вычитано).
- `glossary.md`: имена, термины, тон и типографика. Его обязательно соблюдать при правках.
- `data/manual_ru.json`: ручные переводы одиночных слов, которые игра склеивает в фразы.
- `data/review_notes.md`: известные проблемы, которые нужно поправить при вычитке.
- Перевод новых кусков: `tools/chunk.py` режет непереведённые строки на порции в `work/`,
  `tools/validate.py` проверяет порцию (теги, подстановки, абзацы), `tools/merge.py` переносит
  её в `translations/`. Инструкция для переводчика лежит в `tools/translator_prompt.md`.

Чтобы найти непереведённые строки, запустите игру с `RU_DEBUG=/tmp/ru_missing.txt`: туда
запишется английский текст, для которого не нашлось перевода.
